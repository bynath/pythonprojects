Repositório criado para armazenar meus estudos, exercícios e pequenos projetos desenvolvidos durante meu aprendizado de **Python**.

Atualmente, estou estudando **Análise e Desenvolvimento de Sistemas (ADS)** e utilizando este repositório para registrar minha evolução na programação.

## Sobre o repositório

Aqui você encontrará exercícios e projetos desenvolvidos principalmente durante meus estudos de **Lógica de Programação**, com foco em aprender e praticar os fundamentos da linguagem Python.

Os projetos podem ser simples, mas fazem parte do meu processo de aprendizado e evolução.
