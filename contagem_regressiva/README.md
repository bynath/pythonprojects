### Contagem Regressiva
Um programa em Python que solicita ao usuário um número inteiro positivo e realiza uma contagem regressiva até **1**, exibindo cada número com um intervalo de 1 segundo entre eles. Ao final, o programa exibe uma mensagem indicando o término da contagem.
O programa também valida a entrada do usuário, impedindo valores que não sejam números inteiros ou que sejam menores que 1.

**Conceitos praticados:**

- Biblioteca `time`
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Estrutura de repetição `while`
- Estrutura de repetição `for`
- Estrutura condicional `if`
- Tratamento de erros com `try` e `except`
- Exceção `ValueError`
- Validação de entrada
- Controle de fluxo com `continue` e `break`
- Função `time.sleep()`
- Uso de `range()` com passo negativo
