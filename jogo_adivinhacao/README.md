  ### Jogo de Adivinhação
  Um jogo simples em que o computador sorteia um número aleatório entre **1 e 50** e o jogador precisa tentar descobrir qual é o número.
  A cada tentativa, o programa informa se o número sorteado é **maior ou menor** que o palpite do jogador. O jogo continua até que o número seja descoberto.
  
  **Conceitos praticados:**
  - Biblioteca `random`
  - Entrada de dados com `input()`
  - Conversão de tipos com `int()`
  - Estrutura de repetição `while`
  - Estruturas condicionais `if` e `else`
  - Comparação de valores
  - `break`
  - Uso de f-strings para mensagens dinâmicas
