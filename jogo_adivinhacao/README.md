  ### Jogo de Adivinhação
  Um jogo simples em Python em que o computador sorteia um número aleatório entre 1 e 50 e o jogador precisa descobrir qual é o número.
  A cada palpite válido, o programa informa se o número sorteado é maior ou menor que o palpite. O jogo também contabiliza o número de tentativas e continua até que o jogador acerte.
  Entradas inválidas, como textos ou números fora do intervalo de 1 a 50, são tratadas sem interromper a execução do programa.
  
  **Conceitos praticados:**
  - Biblioteca random
  - Entrada de dados com 'input()'
  - Conversão de tipos com 'int()'
  - Variáveis e operadores
  - Estrutura de repetição while
  - Estruturas condicionais if, elif e else
  - Operadores relacionais e lógicos (<, >, ==, or)
  - Contador de tentativas
  - Operador de atribuição aumentado (+=)
  - Tratamento de erros com try e except
  - Exceção ValueError
  - Controle de fluxo com continue e break
  - Validação de entrada
  - Uso de f-strings para mensagens dinâmicas
